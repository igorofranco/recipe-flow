# recipe-flow

[![CI](https://github.com/igorofranco/recipe-flow/actions/workflows/ci.yml/badge.svg)](https://github.com/igorofranco/recipe-flow/actions/workflows/ci.yml)

Demo de execução de uma receita de produção farmacêutica: o operador percorre as etapas em um grafo,
avança apenas com o registro obrigatório preenchido e acompanha a trilha de auditoria do lote.

## Como rodar

```bash
npm install
npm run dev
```

| Ação      | Comando                 |
| --------- | ----------------------- |
| Dev       | `npm run dev`           |
| Build     | `npm run build`         |
| Typecheck | `npm run typecheck`     |
| Lint      | `npm run lint`          |
| Formatar  | `npm run format`        |
| Testes    | `npm run test`          |
| Cobertura | `npm run test:coverage` |
